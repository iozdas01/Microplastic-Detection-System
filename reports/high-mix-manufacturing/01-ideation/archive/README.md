# Archived lineage

`hunch-lineage-cabinets-2026-09-02.md` holds the first lineage for this idea: H1 (fitted
cabinetry via the trade channel), H2 (structural steel estimating), H3 (US panel goods),
H4 (custom millwork). All four were retired on 2026-09-02 without a single customer
conversation — they were desk-research candidates, not tested hunches.

Archived rather than deleted so their IDs stay burned. The live lineage restarts at H1 with
a different subject, which is only safe because nothing live still cites the old IDs: the
cabinet assumption graph (H1A1-H1A8) is archived alongside it in
`02-assumptions/archive/`, and no evidence entry survives into the new graph.

Why each died is recorded in the archived file itself.
